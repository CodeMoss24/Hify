### 📜 文件作用与全局规则

`CLAUDE.md` 是你给AI助手（Claude Code）的**最高行动纲领**。它告诉AI项目是做什么的、不做什么、要遵循哪些原则。

-   **“一个人开发...以Docker Compose一键部署为核心交付形式”**
    *   **解读**：这是在提醒AI：“我的团队只有我自己，没有专业的运维”。所以，所有技术方案都必须简单，能用 `Docker Compose` 一键启动和升级。AI不能推荐需要复杂K8s集群或手动配三天才能跑的方案。

### 🎯 产品定位：做什么

这一部分定义了项目的核心功能，是你的“作战地图”。

-   **多模型提供商管理**
    *   **原因**：这是平台的基础。一个AI平台如果不能接入不同的模型（如OpenAI, Claude, 本地Ollama），就失去了灵活性，所以它是地基。
-   **Agent创建与配置**
    *   **原因**：这是产品的**灵魂**。单纯聊天机器人很容易做，但Agent能调用工具自主完成任务，是区别于“套壳”产品的核心。
-   **对话引擎（流式响应）**
    *   **解读**：“流式”即“打字机效果”，让用户感觉AI在“思考”，体验更好。这是现代AI应用的标配。
-   **知识库+RAG（一期只支持TXT）**
    *   **原因**：这是**投入产出比极高**的功能。能让AI基于团队内部文档回答问题。只支持TXT是为了一期**快速上线**，因为解析PDF、Word很复杂（格式多、排版难），你一人开发耗不起。
-   **简版工作流（JSON配置，不做可视化）**
    *   **原因**：即“模块组装”，让Agent按设定步骤干活。用JSON配置牺牲了操作友好性，但极大降低了开发成本。可视化拖拽是另一个“时间黑洞”，前期必须避开。
-   **MCP工具接入**
    *   **原因**：MCP是“万能充电接口”，让Agent能调用外部工具（如查天气）。这是**紧跟前沿且保持平台扩展性的关键**。
-   **管理控制台**
    *   **原因**：用户操作入口。没有它，用户就得面对黑框敲命令行了。

### 🚫 产品边界：不做什么

在你看来这是“功能清单”，在架构师眼里这是**护城河**，决定项目生死。不懂拒绝，项目就会被无限蔓延的需求拖垮。

-   **不做可视化工作流拖拽编排**
    *   **原因拆解**：
        1.  **逻辑极重**：实现节点拖拽、连线、校验，前端代码量巨大，Bug极多。
        2.  **不是刚需**：20-50人团队通过修改JSON配置完全能搞定，可视化是锦上添花，不是雪中送炭。
        3.  **投入产出比极低**：花80%时间做20%人用的功能，对一人项目是致命错误。
-   **不做多租户/权限体系**
    *   **原因**：20-50人内部团队都是“自己人”，无需隔离数据（多租户）或设置角色权限。这些是企业级功能，但你做的是**团队工具**，不是SaaS产品。
-   **不做插件市场、计费系统**
    *   **原因**：插件市场需要开发者生态，计费系统要对接支付。这两件事本质是**运营**，而非技术，对内部工具完全多余。
-   **不做文本生成应用、WebApp发布、嵌入组件**
    *   **原因**：这是对标Dify等平台功能，是把AI应用**对外发布成产品**。你的目标是“对内提效”的协作工具，不是建站工具，这个边界要划清。
-   **不做标注与微调**
    *   **原因**：涉及模型训练或微调，需要大量标注数据和GPU算力。20-50人用现成API足够，这属于**过度投入**。

### 🛠️ 技术栈

你为AI定好的工具集。

-   **后端：FastAPI + SQLAlchemy**
    - **解读**：你选Python系很务实。FastAPI性能不错、写API快，SQLAlchemy是Python最成熟的数据库ORM工具。对Python熟练的小白开发者来说，“顺手”就是最大优势。
-   **向量数据库：Qdrant**
    - **解读**：一个专为AI设计的“相似度搜索引擎”。它专门存储和检索向量（文字语义坐标），处理速度和功能比pgvector这类插件更强大。你用Docker部署把它也“一键化”，很聪明。
-   **容器化：Docker + Docker Compose**
    - **解读**：你的环境一致性“保护伞”。通过`compose`文件一键启动所有服务，未来给别人用时，无需痛苦配环境。
