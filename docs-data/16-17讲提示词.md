### 3. 任务三：ChatService.send_message 六步链路

**做什么：** 实现对话引擎最核心的方法——六步链路完整落地：查配置 → 取历史 → 存用户消息 → 拼装 messages → 流式调 LLM → 存 AI 回复。同时给 ProviderAdapter 基类扩展 `stream_chat` 方法，三个 Adapter 分别实现。

**目的：** 这是整个 Hify 项目最核心的方法。用户输入一句话到看到 AI 流式回复，全部处理逻辑都在这里。

**提示词（Python 版本）：**

> 在 `app/chat/service.py` 里实现 `send_message` 方法，完整落地第 16 讲设计的六步链路。这是整个对话引擎最核心的方法。
>
> **方法签名：**
> ```python
> async def send_message(
>     self,
>     db: Session,
>     agent_id: int,
>     content: str,
>     conversation_id: int | None = None,
> ) -> AsyncGenerator[str, None]:
> ```
>
> **六步流程：**
> 1. **查配置**：调 `agent_service.get_agent` → `model_service.get_model` → `provider_service.get_provider`
> 2. **取历史**：调 `context_manager.get_history(db, conversation_id, max_context_turns)`
> 3. **存用户消息**：`MessageModel(role="user", content=content)`，`db.add` + `db.commit`
> 4. **拼装 messages**：`[system] + history + [user]`
> 5. **流式调用 LLM**：通过 `provider_adapter_factory.get_adapter(provider_type)` 获取 Adapter，调 `adapter.stream_chat(...)`，逐条 yield SSE 格式 `data: {"type":"delta","content":"..."}\n\n`，记录 latency_ms，发送 `data: {"type":"done","finishReason":"stop","latencyMs":xxx,"conversationId":xxx}\n\n`
> 6. **存 AI 回复**：`MessageModel(role="assistant", ...)` 存库 + `context_manager.add_message` 更新 Redis
>
> **异常处理：** LLM 失败时存 `finish_reason="error"` 消息，yield 错误 SSE 事件。BizException 单独捕获并 yield 错误信息。
>
> **Router 集成：** 新增 `POST /conversations/{id}/messages` 和 `POST /agents/{id}/chat` 端点，返回 `StreamingResponse(content_type="text/event-stream")`
>
> **Adapter 扩展：** 给 `ProviderAdapter` 基类新增 `stream_chat` 抽象方法（接收 provider、model、messages、agent_config，返回 `AsyncGenerator[str, None]`）。三个 Adapter 分别实现：OpenAI 用 `asyncio.Queue` 实现流式解析、Anthropic 处理 system 消息分离、Ollama 适配原生格式。
